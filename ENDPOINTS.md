# Endpoints

## Public Pages

- GET /
  - Home page listing the latest posts.

- GET /pages/post.php?id=<id>
  - Single post page by numeric id.

## Health and Debug

- GET /health.php
  - Returns JSON with database status.
  - Example response: {"status":"ok","db":1}

- GET /dbTest.php
  - Simple database connectivity test page.

## SEO Files

- GET /sitemap.xml
  - Sitemap generated by scripts/build-sitemap.js.

- GET /robots.txt
  - Robots directives for the site.
